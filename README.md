# Proonima Misra — Online Hindi Tutor

Single-page static website for Proonima Misra's online Hindi classes.

## Deploy with Vercel

Import this GitHub repository into Vercel. No build command or framework preset is needed; `index.html` is served from the project root. Every push to `main` will deploy automatically once the repository is connected to the Vercel project.

## Local preview

Open `index.html` in a browser. The booking form and WhatsApp links open a pre-filled message to the configured WhatsApp number.
